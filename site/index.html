From an extreme value to its source От экстремального значения к его источнику

EVT answers when an observation became extreme. A dependence graph describes the plausible propagation paths. GNN/GAT answer where the event started. Everything below runs live in your browser — move any slider and every number is recomputed.

EVT отвечает на вопрос, когда наблюдение стало экстремальным. Граф зависимостей описывает допустимые пути распространения. GNN/GAT отвечают, где событие началось. Всё ниже считается прямо в браузере — двигайте любой слайдер, и все числа пересчитываются.

What the Hurst exponent H doesЧто делает показатель Хёрста H

ηH is built in the Fourier domain with amplitude ∝ f−(H−½), so its power spectrum falls as f−(2H−1). H < 0.5 is anti-persistent (rough), H = 0.5 is white, H > 0.5 is persistent (long memory, smooth swings). DFA recovers H as the slope of the fluctuation function F(s) ∝ sα. Both panels use a long 2048-sample draw of the same noise.

ηH строится в частотной области с амплитудой ∝ f−(H−½), поэтому спектр мощности спадает как f−(2H−1). H < 0.5 — антиперсистентный (шероховатый) шум, H = 0.5 — белый, H > 0.5 — персистентный (длинная память). DFA восстанавливает H как наклон флуктуационной функции F(s) ∝ sα. Обе панели — длинная реализация того же шума (2048 отсчётов).

    How GNN and GAT find the sourceКак GNN и GAT находят источник
    
      
    Both models score every node and take a softmax over nodes, so the output is a ranking of candidate sources. They differ in how a node
        hears its neighbours: the GNN uses fixed graph averages, the GAT learns per-episode attention weights over the frozen edges.
        Both are trained by cross-entropy on many independent labelled episodes — one recording is not a training set.
    
      
    Обе модели оценивают каждый узел и берут softmax по узлам, поэтому на выходе — ранжирование кандидатов в источник. Различие —
        в том, как узел «слышит» соседей: GNN использует фиксированные средние по графу, GAT обучает веса внимания по зафиксированным рёбрам
        для каждого эпизода. Обе обучаются по cross-entropy на многих независимых размеченных эпизодах — одна запись не является обучающей выборкой.

    Competing graph hypothesesКонкурирующие гипотезы графа
    
      
    The graph is a testable dependence hypothesis, not proof of causality. The rule from the method: if the baseline is approximately
        stationary, use AR-innovation dependence; otherwise test cross-DFA and Kuramoto + wavelet phase locking. auto applies exactly this
        rule and, when non-stationary, keeps only the edges both non-stationary hypotheses agree on.
    
      
    Граф — проверяемая гипотеза зависимости, а не доказательство причинности. Правило метода: если фон приблизительно стационарен —
        зависимость AR-инноваций; иначе — проверить cross-DFA и фазовую синхронизацию Курамото + вейвлеты. auto применяет именно это
        правило и для нестационарного фона оставляет только рёбра, на которых сходятся обе нестационарные гипотезы.

    1-D temporal graph: time windows as nodesВременной граф 1-D: окна времени как узлы
    
      
    With one channel, graph_evt_agent.temporal cuts the series into overlapping windows (window_size, stride);
        each window is a node linked to its neighborhood. Node features are the same five as in n-D plus onset-context columns:
        log-energy of baseline-AR innovations over horizons after the window start, and its contrast with the horizon before. Without that context the
        model finds the end of the event (its maximum) rather than its onset. The target is the window containing the onset; the prediction is
        mapped back to [start, start + window_size).
    
      
    С одним каналом graph_evt_agent.temporal нарезает ряд на перекрывающиеся окна (window_size, stride);
        окно — узел, связанный с соседями (neighborhood). Признаки узла — те же пять, что в n-D, плюс столбцы контекста начала:
        log-энергия AR-инноваций (модель по фону) на горизонтах после начала окна и её контраст с горизонтом до. Без контекста модель находит
        конец события (максимум), а не начало. Цель — окно, содержащее onset; предсказание отображается обратно в
        [start, start + window_size).
