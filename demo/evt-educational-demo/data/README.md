# Исследовательские данные

`fractal_extreme_series.csv` — фиксированный одномерный учебно-исследовательский ряд из 4096 наблюдений (`time`, `value`). Он создан воспроизводимо с seed `271828`: фон с приблизительным спектром $1/f$, мультипликативная волатильность на масштабах 16, 64 и 256 отсчётов и пять гладких импульсов. Метки импульсов намеренно не публикуются в CSV: ноутбуки рассматривают ряд как неразмеченный объект исследования, а не как задачу с известным ответом.

Данные созданы авторами этого репозитория (CC0). Это синтетический стенд для обучения; он не подтверждает фрактальность природного процесса и не подходит для предметных решений. Старый `synthetic_data.csv`, который не использовался актуальным сценарием, удалён.
