# Исследовательские данные

Все артефакты в этом каталоге воспроизводятся командой:

```bash
python data/generate_datasets.py --seed 42
```

`fractal_extreme_series.csv` — одномерный учебный ряд из 1500 наблюдений с колонками `timestamp`, `value`, `is_extreme`. Фон — конечная спектральная аппроксимация фрактального гауссовского шума с $H=0.75$; поверх него добавлен один гладкий импульс амплитудой 8 стандартных отклонений. Метка отмечает только внедрённый интервал.

`kuramoto_synchronized_series.csv` — 12 наблюдаемых каналов глобально связанных осцилляторов Курамото. В источник `channel_00` на двух третях ряда вносится фазовое возмущение. PNG-файлы дают быстрый визуальный контроль, а `synthetic_datasets_metadata.json` фиксирует параметры и диагностические значения.

Генератор принимает seed, показатель Хёрста, число каналов, источник, длину и выходной каталог. Данные созданы авторами репозитория (CC0). Это синтетические стенды для обучения: спектральная конструкция не является точным fGn-сэмплером, не подтверждает фрактальность природного процесса и не подходит для предметных решений.
